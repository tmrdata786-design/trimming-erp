## Sync Strategy

### Initial Sync (on app startup / manual refresh)
1. Fetch all Inventory Items with custom fields → cache in IndexedDB + PostgreSQL
2. Fetch all Inventory Locations (hierarchy) → cache
3. Fetch all Suppliers with custom fields → cache
4. Fetch all Employees with custom fields → cache (if module enabled)
5. Fetch current stock balances (via Inventory Transactions or Balance Sheet) → cache

### Incremental Sync
- On PTN/Inventory Transfer creation: update local cache immediately
- Periodic background sync (5 min) for stock balances
- Manual "Refresh from Manager.io" button in Master Data view

### Conflict Resolution
- Manager.io wins for master data (items, locations, suppliers, employees)
- Application wins for operational data (work orders, QC, rework, OGP/IGP)
- Stock balance conflicts: show discrepancy, require manual resolution

## Dropdown Value Mappings (for Text→Dropdown Conversion)

### Trimming Item Type (Inventory Item)
- `Untrimmed Moulding` → `untrimmed_molding`
- `Intermediate` → `intermediate`
- `Trimmed Finished` → `trimmed_finished`

### Rework Rule (Inventory Item)
- `Unpaid Original` → `unpaid_original`
- `Standard Rate` → `rate_applicable`
- `Supervisor Decision` → `supervisor_decision`

### Vendor Category (Supplier)
- `In-House Piece-Rate` → `in_house_vendor`
- `Outsourced` → `outsourced_vendor`

### Default Shift (Supplier, Employee)
- `Shift A` → `SHIFT_A`
- `Shift B` → `SHIFT_B`
- `Shift C` → `SHIFT_C`

### Production Stage (Inventory Transfer)
- Values derived from Item routing configuration (app-managed)
- Examples: `Primary Trimming`, `Secondary Trimming`, `De-burring`, `Polishing`, `Final Inspection`
